SAMPLE DOCUMENTS
================

This folder contains sample document templates for customers to reference when uploading their rental documents.

FILES:
------
1. sample_contract.txt - A sample rental contract template showing all required fields and format (plain text)
2. sample_id.png - (Add your own sample ID image here - e.g., sample driver's license)

USAGE:
------
- Customers can view/download the contract sample to see required fields
- Add a sample ID image (PNG format) showing customers what valid ID looks like
- Samples help customers understand document requirements

NOTE:
-----
These are TEMPLATES/REFERENCES only. Customers must upload their own:
- SIGNED rental contract (PDF or photo)
- ACTUAL valid government-issued ID (Driver's License, Passport, National ID)

Accepted formats for upload:
- Contract: PDF, JPG, PNG (max 10MB)
- ID: PDF, JPG, PNG (max 5MB)

TO ADD YOUR OWN SAMPLE ID IMAGE:
--------------------------------
1. Create a sample/driver's license image (PNG format recommended)
2. Name it: sample_id.png
3. Place it in this folder: public/sample_documents/
4. The upload page will automatically display it
